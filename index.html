ASO Keyword Gap Audit

PeekPanda compares stored US English App Store search observations between your tracked iOS app and a rival — splitting them into queries only the rival ranks for, queries you both rank for, and queries only your app ranks for. Paste one or more gap responses below to combine multiple rivals, surface consensus gaps and striking-distance head-to-heads, and diff against an earlier run. Everything runs locally in your browser; nothing is sent anywhere.

Positions are observed US App Store search positions from stored snapshots, not native App Store ranks or search volume. An empty side means those searches were not in the collected set for that app, not zero.

Where to get the JSON

Reading keyword gaps needs a PeekPanda account (scope context:read) and counts toward your plan's daily API and MCP allowance; the GET endpoint returns stored observations and never calls Apple. See Keyword gap, Get ASO keyword gap, List ASO apps, and plans and refreshes: 

curl --get 'https://api.peekpanda.com/v1/aso/apps/YOUR_APP_UUID/gap/RIVAL_STORE_ID' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --header 'x-genviral-tenancy: personal' > gap.json
Part of a small set of open-source PeekPanda API tools. Source and Node CLI: github.com/fdarkaou/aso-keyword-gap-audit (MIT). Example data uses synthetic store IDs and made-up apps.
